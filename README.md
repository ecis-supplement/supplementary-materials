# Supplementary Materials: Tensions and Responses in News Personalisation

This repository provides the concept matrix and accompanying coding documentation for a systematic literature review of tensions in news personalisation and organisational responses to them. The supplementary workbook covers **74 publications** and contains the codebooks, illustrative data structures and episode-level coding evidence.

## Workbook

**[Download Supplementary Coding Evidence.xlsx](https://github.com/ecis-supplement/supplementary-materials/releases/tag/v1.0.0)**

Open the downloaded workbook in Microsoft Excel to view its seven worksheets, including the embedded data-structure figures.

| Worksheet | Contents |
| --- | --- |
| `Concept Matrix` | The 74 included publications, with publication year, title, source citation, DOI and the tension themes and response categories identified in each publication. |
| `Codebook_Tension` | Definition and identification criteria for tension episodes; the 22 first-order concepts, their definitions, second-order themes, aggregate dimensions, classification boundaries and record counts. |
| `Tensions_Data_Structure_Example` | An illustrative four-layer tension data structure, from episodes through first-order concepts and second-order themes to aggregate dimensions. |
| `Codebook_Response` | Definition and identification criteria for response episodes; the 17 first-order concepts, their definitions, second-order categories, aggregate orientations, classification boundaries and record counts. |
| `Response_Data_Structure_Example` | An illustrative four-layer response data structure, from episodes through first-order concepts and second-order categories to aggregate orientations. |
| `Tensions_Coding_Evidences` | All 679 tension episodes in this supplement, with source citations, first-order codes, second-order themes, aggregate dimensions and classification rationales. |
| `Response_Coding_Evidences` | All 700 response episodes, with source citations, first-order codes, second-order categories, aggregate orientations and classification rationales. |

## Coding structure

The workbook distinguishes individual coding episodes from the first-order concepts that consolidate them:

| Coding level | Tensions | Responses |
| --- | --- | --- |
| Episodes | 679 | 700 |
| First-order concepts | 22 | 17 |
| Second-order themes or categories | 6 | 6 |
| Aggregate dimensions | 3 logic dyads | 3 response orientations |

A **tension episode** describes a source-supported opposition between competing requirements in a particular news-personalisation context. A **response episode** describes a distinguishable organisational action, arrangement, practice or deliberate non-action addressing, or intended to address, a tension. The codebooks specify the identification criteria and the classification boundary for each first-order concept.

The tension dimensions are **Technological–Journalistic**, **Technological–Economic** and **Journalistic–Economic**. The response orientations are **Either-Or Approaches**, **Both-And Approaches** and **More-Than Approaches**.

## How to read the materials

1. Start with `Concept Matrix` for a publication-level overview. The abbreviations used in its columns are explained below the matrix.
2. Consult the two codebooks for the definitions and boundaries of the coding categories. The `Records` column gives the number of episodes assigned to each first-order concept.
3. Use the data-structure sheets to see how the four coding levels connect. Both figures show all six second-order groups and all three aggregate dimensions. The episode and first-order columns show selected first and last examples within each second-order group; `...` indicates omitted entries.
4. Consult the two coding-evidence sheets for the complete episode lists and their classification rationales. Citations spanning merged cells apply to all episodes within the corresponding merged range.

## Interpreting the evidence

- An `x` in the concept matrix indicates that at least one retained coding record supports that publication–category combination. A blank means no retained record was assigned to that cell; it does not establish that the issue is absent from the publication. Matrix marks indicate presence, not episode frequency, and co-occurrence alone does not establish a tension–response relationship.
- Episode descriptions are analytical coding labels, rather than verbatim quotations from the original publications. Publication titles and DOIs are provided in the concept matrix, and the evidence sheets identify sources through author–year citations.
- Responses include source-supported proposals as well as reported or evaluated measures. Consult the classification rationale for context and evidence qualifications; inclusion does not itself establish implementation or effectiveness.
- Episode counts refer to coding units. A publication may contribute multiple episodes, so these counts should not be read as numbers of independent studies, organisations or participants. Connections in the data-structure figures represent coding relationships, rather than causal or temporal sequences.
